E-Sys launcher: what it does

Why E-Sys is started through a launcher, what a good one sets up for you, and how the E-Sys MAX launcher works.

What is an E-Sys launcher?

E-Sys is BMW's engineering tool for coding F-series, G-series and I-series cars. It is a Java program with many settings that are read once, when it starts: how much memory it may use, where the PSdZData is, which connection to use, and more.

An E-Sys launcher is a small Windows program that starts E-Sys with those settings already right, so you do not have to edit configuration files by hand. People call it "E-Sys launcher", "Esys launcher" or just "the launcher".

What a launcher should set up for you

  • The E-Sys version. Many coders keep several versions (for example 3.40, 22.10 and 25.10). The launcher should find them all and start the one you pick.
  • Memory. Newer PSdZData packs are large, and E-Sys with too little memory becomes slow or stops with "out of memory" while reading a car. The launcher sets the memory per version.
  • PSdZData. E-Sys needs the data for your car's I-step. The launcher points each E-Sys version at the right folder.
  • The connection. ENET cable or ICOM, gateway address and firewall: if E-Sys cannot see the car, nothing else matters. A good launcher checks this before E-Sys even opens.

The E-Sys MAX launcher

E-Sys MAX comes with its own launcher. It works with the E-Sys you already have; E-Sys itself is not included.

  1. Finds every E-Sys version on your PC by itself and lists them on Home.
  2. Setup check: E-Sys, PSdZData and the ENET cable, each green when ready, with a hint when something is missing.
  3. Car connection check: finds the car or the ICOM on the network, checks the firewall and the gateway address, and tells you what to fix in plain words.
  4. Memory and PSdZData per version, set once and kept.
  5. Press play: E-Sys opens with E-Sys MAX inside, so the FDL-Editor shows settings in English, the What can I code? list, the fault scan, backups and coding history.

The launcher also holds your licence and updates: when a new version is out it says so and installs it with one click, signed so nobody else can slip in a fake update.

What a launcher does not do

A launcher does not change what E-Sys writes to the car, and it cannot make a module do something its software does not support. The coding itself still happens in E-Sys, one module at a time, after you press Code. E-Sys MAX adds a safety check before that write and keeps a backup so you can put the old coding back.

Questions

Do I need a launcher to use E-Sys?

You can start E-Sys on its own and set everything by hand. A launcher saves that work, avoids the most common start problems (too little memory, wrong PSdZData folder, no connection) and, with E-Sys MAX, adds English setting names inside E-Sys.

Which E-Sys versions does the E-Sys MAX launcher start?

Every version from 3.x to 25.x. 25.10, 24.06, 22.10, 22.06 and 3.40 are tested before every release. See Compatibility.

Is E-Sys included?

No. E-Sys and PSdZData are BMW software. E-Sys MAX works with the E-Sys already installed on your PC.

Does the launcher need internet?

Only once a week, for the licence check. Coding at the car needs no internet.
