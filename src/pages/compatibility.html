Why G-series has fewer names: BMW never published names for G-series settings. See E-Sys cheat sheets. Know a setting? Name it and send it with Help improve names: names we add earn you free licence time.

Connection to the car

ConnectionStatus
ENET cable (Ethernet to OBD)Supported: the usual way
BMW ICOM over Ethernet (Connection via ICOM/Ethernet)Supported since 2.0.10; tested with a simulated ICOM, not yet with a real one
Newer DoIP cars (port 13400)Supported since 2.1.0: the fault scan, module info and battery reading speak DoIP too; tested with a simulated DoIP gateway, not yet with a real car
Bluetooth or Wi-Fi OBD dongles, K+DCAN cablesNot supported: E-Sys itself cannot use them

PC

PCStatus
Windows 11 or 10, 64-bit, Intel or AMD processorSupported
Windows on ARM (Snapdragon laptops)Not recommended: E-Sys runs through emulation, and some USB network adapters have no ARM driver
Mac, or Windows in a virtual machineNot on our test list
InternetOnce a week, for the licence check. Coding itself needs no internet.
