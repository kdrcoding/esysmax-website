BMW VO coding and option codes

How the vehicle order works, how to add or remove an option code with E-Sys, and the codes you will meet most often.

What is VO coding?

Every BMW carries its vehicle order (German Fahrzeugauftrag, so FA; in English also VO). It lists how the car was built: series, type key, build date, paint and upholstery, and every factory option as a three-character option code (SA code), for example 5AC for the high-beam assistant.

Modules read the vehicle order to decide which functions to switch on. VO coding means changing that list (adding or removing an option code) and then recoding the modules, so they all switch the function on or off together. It is the clean way to "retrofit" an option the hardware supports, for example after fitting a reversing camera.

Changing one setting in one module is the other way: FDL coding.

Step by step: add or remove an option code

  1. Connect with a charger on the battery, Read FA and save a copy of the original FA file.
  2. Open the FA in the editor (in E-Sys: Expert Mode > VCM > Read from the car, then Edit).
  3. Under SALAPA, add the option code (or remove it). Most codes need the leading $, for example $5AC.
  4. Calculate FP where your E-Sys version shows it, then Save and Write FA (and the FP) to the car.
  5. Read FA again and Activate FA, then Read SVT.
  6. Select the modules the option touches and press Code (not "Code Default Values" unless you want every FDL change reset).

Be careful: an option code tells every module the part is there. Adding a code for hardware the car does not have can cause fault messages. Removing codes can switch functions off in modules you did not expect. Change one code at a time and keep the original FA.

Questions

VO coding or FDL coding: which one should I use?

VO coding when you add or remove a whole option (hardware fitted or removed). FDL coding for a single setting in one module. Do VO changes first: recoding from the vehicle order resets FDL changes in the modules it touches.

What is the $ in front of an option code?

It marks a SALAPA option code in the FA. E-Sys's editor shows codes with it, for example $5AC. Type it the same way.

Where can I see my car's option codes?

Read the FA with E-Sys: the SALAPA list is every option your car was built with (plus any added later). E-Sys MAX shows each one with its English name.
