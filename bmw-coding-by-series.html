E-Sys coding by series

Find your car by its chassis code (F30, G20, F15 and so on): does E-Sys code it, and what to expect.

Find your chassis code

BMW names each generation with a chassis code: E for older cars, F from about 2008, G from about 2015, and I for the i3 and i8. The code is in your car's papers, on many parts lists, and E-Sys shows it after Read FA (for example F030 or G020).

E-Sys codes F, G and I-series cars, plus MINI and Toyota Supra models built on them. Older E-series cars use other tools. In every case you need E-Sys, the PSdZData for your car's I-step, an ENET cable or ICOM and a battery charger.

What changes between series

  • The modules. The same feature can live in a different module: the body module is FEM on many F-series cars and BDC on later F and G-series cars; the head unit can be NBT, NBT EVO or MGU.
  • The CAFD version. A setting can move or change meaning between versions, so a cheat sheet line for one series may not fit another.
  • The PSdZData. Newer cars need newer data. See PSdZData versions and I-steps.

E-Sys MAX's What can I code? list only shows the changes that fit the module and CAFD in your car, so you do not have to sort this out by hand.

Questions

Can E-Sys code my E90 or E60?

No. E-series cars use an older system that E-Sys does not code. E-Sys starts with the F-series.

Does E-Sys MAX work on G-series?

Yes. Everything works on G-series; there are just fewer English names because BMW never published them. Every update adds more, and names you send with Help improve names earn you free licence time.
