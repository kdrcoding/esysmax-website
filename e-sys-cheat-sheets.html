E-Sys cheat sheets: how to use them

What a cheat sheet is, how to read one, and how to apply a change safely, on F-series and G-series cars.

What is a cheat sheet?

A cheat sheet is a list of coding changes people have tried on real cars. Each line tells you, for one feature:

  • the module it lives in (for example the head unit, the body module, the instrument cluster or the footwell module),
  • the setting: its name, or where it sits in the module's settings when it has no name,
  • the value to set (often from nicht_aktiv, off, to aktiv, on),
  • and often which series and CAFD versions it was tested on.

Cheat sheets exist because E-Sys itself does not explain what a setting does. Many come from coding forums; some are shared as XML files that tools can read.

How to apply a line from a cheat sheet

  1. Connect, read the vehicle order and press Activate FA, then read the module list (SVT). Our beginner's guide has every step.
  2. Select the module named on the sheet and Read Coding Data. Keep this file: it is your way back.
  3. Right-click the module's CAFD and choose Edit FDL. Find the setting, change it to the value on the sheet, and save.
  4. Select the CAFD and press Code. Test the feature with the ignition off and on again.

Check the version. A setting can move between CAFD versions, and a line made for one series can mean something else on another. Prefer lines tested on your series, and change one thing at a time.

Why do many settings show as "."?

Since around 2016 BMW removes the names of settings from the data E-Sys uses, so E-Sys shows a dot for most of them. F-series modules existed before that, so older data still names most of them. G-series modules never had names in public data, which makes G-series cheat sheets short and hard to follow: they can only say "block 3000, byte 12, bit 2".

Questions

Are cheat sheets the same for every car?

No. A setting depends on the module, its CAFD version and the series. A line can be right for one car and wrong for another, so check what it was tested on.

Where can I find a G-series cheat sheet?

G-series lists are smaller because BMW never published names for those modules. Coding forums and open community lists have some. E-Sys MAX brings the open community sheets in by itself and adds new G-series names with every update.

What if a change does not work?

Code the module's saved coding file back. In E-Sys MAX, Coding history shows exactly which settings changed and opens the older version to put it back.
